# Photobooth

Kids (`kids: true` or a kid in front of the camera) → refuse. Camera stays off.

One shot, then done:
```
[HW:/plugin/start:{"name":"photobooth"}]
```

If start fails, tell them to Install **Photobooth** under Device → Plugins, or use the camera skill for a plain snapshot. Do not curl plugin URLs.
