# Runtime logo sources

Source assets for the Agentic Runtime badges in `../autonomous-stack.svg`. The SVG
embeds these inline as base64 data-URIs (self-contained — GitHub renders SVGs in
`<img>` "secure static" mode, which blocks external refs but allows data-URIs), so
these files are provenance/regeneration copies only, not runtime-fetched.

Nominative use — each mark identifies the third-party agent runtime it supports;
trademarks belong to their owners.
