# Brains

The OS is the platform. The **brain** is swappable.

**Companion loop** (Talk, skills, name, wake, speaker): OpenClaw (default here) or Hermes.

**Coding CLIs** behind a bridge: Codex, Claude Code, OpenCode. They do not automatically get morning brief, greeter, or HAL tools.

PicoClaw is Telegram-only. WhatsApp is OpenClaw only.

Switch under Device → Runtime (Advanced). First switch can take minutes. The box restarts. The **model key** (Device → AI Brain) still has to match the new brain — Claude Code wants Anthropic, Codex wants OpenAI.

Live chat history does not move. Name, soul, and MEMORY.md do.

Do not switch to try a coding CLI unless you mean to debug.

Lima (`kestrel-host`) on this Mac is a full OpenClaw bot with Grok, no motors. See [Dummy host](dummy-host).
