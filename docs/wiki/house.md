# House

House is how it lives here.

**Behaviors** is the pack: mornings, remember, dance, stories, kids, kitchen windows, and **Ask before sending**. Guided setup walks the same ground. **Home Assistant** is also here: URL + token, then a Matter pairing code so this robot can add a bulb to the house. The robot is the commissioner, not a Matter accessory. See [Hive](hive).

**Quiet hours** is bedtime. Mic, speaker, and motion stay down. Walking past does not wake it. Fire still does.

**People** is who it knows. See [People](people).
