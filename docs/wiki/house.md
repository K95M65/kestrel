# House

House is how it lives here.

**Behaviors** is the pack: mornings, remember, dance, stories, kids, kitchen windows, and **Ask before sending** (the same four levels ChatGPT uses for apps). Guided setup walks the same ground. **Home Assistant** is also here: URL + token, then [Add a Matter accessory](hive) — scan-the-box, not this robot joining Apple Home. See [Compared with Siri and ChatGPT](compare).

**Quiet hours** is bedtime. Mic, speaker, and motion stay down. Walking past does not wake it. Fire still does.

**People** is who it knows. See [People](people).
