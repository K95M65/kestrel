# Claim this robot

Home shows a second QR while nobody has claimed the body.

Apple Home: plus → Add Accessory → scan the code on the box → name → room.
Google Home: plus → scan or type the Matter code → home → room.

This robot: scan **Claim this robot** on the same Wi-Fi. Type your name and a room. That person is the **owner**. The setup code is the secret — like a HomeKit accessory code. It is not an Apple or Google account, and the body does not appear in those apps.

After it is claimed, House → People can **Invite** someone. They open `/claim` and type that invite code. Pick a role: family, kid, or guest.

Kid is the same bound as Kids around: no mail, calendar, or computer-use.
