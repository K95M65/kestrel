# Claim this robot

Home shows a second QR while nobody has claimed the body.

Scan it on the same Wi-Fi. Type your name and a room. That person is the **owner**.

The setup code is the secret — like a HomeKit accessory code. It is not an Apple or Google account.

After it is claimed, House → People can **Invite** someone. They open `/claim` and type that invite code. Pick a role: family, kid, or guest.

Kid is the same bound as Kids around: no mail, calendar, or computer-use.
