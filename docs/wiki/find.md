# Find this robot

Home shows **This robot**: a URL, a copy button, and a QR code.

Use the **IP address** on another computer on the same Wi-Fi. The `.local` name is extra — many home routers drop it.

If nobody has claimed it yet, a second QR is **Claim this robot** — name, room, owner, like Apple Home’s Add Accessory. It does not join Apple or Google Home. See [Claim](claim).

A second Kestrel on this Wi-Fi joins under Device → Channels → Talk to another robot (hive join QR). See [Hive](hive).

This page is not a scan of every Kestrel on the LAN. It is this one body.
