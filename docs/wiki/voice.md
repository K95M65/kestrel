# Voice

Device → Voice is how the robot sounds.

**On robot** plays through the speaker. Unmute on Home first if it shows MUTED.

**In this browser** plays the same voice on this computer. The robot can stay muted. Useful when you are not at the desk, or the dummy host has no speaker.

The key for the voice service never leaves the device. This page only asks the robot to render a short line.

My Voice (who *you* are) lives on House → People, not here.
