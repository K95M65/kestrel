Hello Robot

A starter plugin for Kestrel — rainbow LEDs + voice greeting

# What it does
POST /led/effect  {"effect": "rainbow"}
POST /voice/speak {"text": "Hello!"}
# ...wait 30s, then LED off
  1. Fork this Space
  2. Edit main.py to do something cool
  3. On your device: Settings > Plugins > paste URL > Install
